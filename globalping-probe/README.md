# Home Assistant App: Globalping Probe

Runs a [Globalping](https://globalping.io) probe on your Home Assistant host, contributing
to a globally distributed network that anyone can use to run ping, traceroute, mtr, DNS and
HTTP measurements. Hosting a probe earns you credits and higher API rate limits.

Powered by [globalping-probe](https://github.com/jsdelivr/globalping-probe).

## Setup

1. Sign in at [dash.globalping.io](https://dash.globalping.io) and copy your adoption token.
2. Paste it as **Adoption Token** in this app's configuration.
3. Start the app.
